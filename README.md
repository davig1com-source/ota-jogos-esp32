# Atualizações dos jogos ESP32

Este repositório hospeda **só** o arquivo `manifest.json` e os binários
(`.bin`) publicados nas Releases — usado pelos jogos ESP32 (Passa ou
Repassa Bíblico, Central de Jogos P10, etc.) para verificar e baixar
atualizações pela internet.

Não tem código-fonte aqui de propósito, só o necessário para as
atualizações funcionarem. O passo a passo de como publicar uma versão
nova está em `ferramentas_ota/LEIA-ME.md`, na pasta do projeto principal
(fora deste repositório — esse arquivo aqui não sai da sua máquina).
